Logic Explanation

  • The loot array serves as the source of truth by being the source for every part of the code. No section of the loot splitter works without accessing the loot array. The loot array also serves as the only source that is updated and also updates the UI.
  • Quantity was added by simply adding another input area and is multiplying with the already available loot value. As to why it was added, I guess it was just to give more freedom when adding items and to reduce clutter when adding multiple of one.
  • updateUI() calculates totals and renders everything directly after a change is made. This is mainly through the methods that add loot and remove loot. However, it's also called when the party size value updates.
  • State is controlled by the loot array. It determines if loot is split and if totals are shown. The party input state also controls the split section visibility.
  • Conditional logic prevents invalid states by checking each possible outcome with an if else statement. The party section checks if the number is valid and prevents invalid splitting. In combination the split checks if there is loot which also prevents and invalid state. Conditional logic is also used to prevent and invalid inputs from being used as loot.
